# MetaSEMAP

A web-based tool for annotating and reusing declarative mappings using lifecycle-based metadata, supporting the PhD thesis *"A Lifecycle-Based Metadata Model for Improving Documentation, Reuse, and Generation of Declarative Mappings"* (Trinity College Dublin, 2026).

## Live deployment
https://metasemap-1-sarah-alzahrani.replit.app/

The home page provides:
- **Refined version** - uses MMV v0.2, no mandatory upload, outputs either Named Graph (TriG) or Turtle.
- **Study 2 / 4 / 5 versions** - preserved for replicability of thesis evaluation studies.
