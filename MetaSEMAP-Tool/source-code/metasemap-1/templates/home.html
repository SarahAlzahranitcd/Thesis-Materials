Welcome to MetaSEMAP

MetaSEMAP is a software application for annotating declarative mappings using lifecycle-based metadata. The refined version below implements the latest MMV v0.2 ontology and is the recommended entry point for current use. The three study buttons preserve the exact tool versions used in the thesis evaluation studies, ensuring experimental replicability.
