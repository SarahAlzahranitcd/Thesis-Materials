# Thesis Materials

This repository provides the supplementary materials for the PhD thesis:

**"A Lifecycle-Based Metadata Model for Improving Documentation, Reuse, and Generation of Declarative Mappings"**

**Author:** Sarah Alzahrani
**Institution:** Trinity College Dublin
**Year:** 2026
**Supervisor:** Prof. Declan O'Sullivan

---

## Repository Structure

This repository is organised according to the five studies presented in the thesis:

* `publications/` – Associated papers and publications
* `Study-1-Community-Survey/` – Materials and data for Study 1 (Community Survey)
* `Study-2-Usability/` – Materials and data for Study 2 (Usability Evaluation)
* `Study-3-Ontology-Evaluation/` – Materials and data for Study 3 (Ontology Evaluation)
* `Study-4-Reuse-Experiment/` – Materials and data for Study 4 (Reuse Experiment)
* `Study-5-LLM-Generation/` – Materials and data for Study 5 (LLM-Based Mapping Generation)
* `MMV-Ontology/` – Versions of the MMV ontology (TTL files and documentation)
* `MetaSEMAP-Tool/` – Source code, screenshots, and example outputs of the MetaSEMAP tool

Each study folder includes:

* `questionnaire/` – Survey instruments (if applicable)
* `raw-data/` – Anonymised participant data
* `results/` – Processed results and analysis

---

## Ontology

The **Mapping Metadata Vocabulary (MMV)** is available online:

🔗 https://sarahalzahranitcd.github.io/MMV-Ontology2/

The ontology captures lifecycle-based metadata for declarative mappings, supporting improved documentation, evaluation, and reuse.

---

## Tool

The **MetaSEMAP tool** is available at:

🔗 https://metasemap-1-sarah-alzahrani.replit.app/

MetaSEMAP supports the annotation of mapping artefacts using the MMV ontology across different lifecycle phases.

---

## Reproducibility

This repository contains all materials required to reproduce the results presented in the thesis, including:

* Ontology files and versions
* Study datasets and evaluation results
* Tool implementation and example outputs
