# Study 3: Ontology Evaluation of MMV

This folder contains the materials and data for Study 3, an ontology evaluation of the Mapping Metadata Vocabulary (MMV), the OWL formalisation of the Lifecycle-Based Metadata Model for Declarative Mappings (LMMD). Study 3 corresponds to Chapter 5, Section 5.5 of the thesis.

## Purpose

Study 3 evaluated MMV from an ontology engineering perspective, focusing on conceptual clarity, lifecycle coverage, modelling structure, and vocabulary reuse. The evaluation combined an expert review questionnaire (six participants) with automated validation using OOPS! and FOOPS!.

## Contents

* `questionnaire/` - The expert review questionnaire and supporting materials provided to participants.
* `results/` - Anonymised expert responses, and OOPS!/FOOPS! validation outputs.
